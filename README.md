# CODSOFT Task 3 – Data Visualization

## About the Project

This project is part of the CodSoft Data Analytics Internship.

The project focuses on visualizing supermarket sales data using Python.

## Dataset

The dataset used for this project is the Supermarket Sales dataset.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created

1. Bar Chart – Total Sales by Product Line
2. Line Chart – Total Sales Over Time
3. Pie Chart – Sales Distribution by Product Line
4. Histogram – Distribution of Total Sales
5. Scatter Plot – Unit Price vs Quantity

## Project Insights

The visualizations help understand product-line sales, sales trends over time, sales distribution, the distribution of sales values, and the relationship between unit price and quantity.

## Files

- `task3.py` – Python visualization code
- `bar_chart.png` – Bar chart
- `line_chart.png` – Line chart
- `pie_chart.png` – Pie chart
- `histogram.png` – Histogram
- `scatter_plot.png` – Scatter plot
